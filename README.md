# Portfolio Project

## Overview

This project is a professional portfolio website built to showcase frontend and backend development skills, project work, and qualifications. It serves as a polished personal branding platform designed for hiring managers and recruiters, highlighting technical expertise, service offerings, and contact information in a clean, modern layout.

## Features

- Dark, framed "graphite" look: thin borders, corner marks, bento grids and soft glows
- Responsive layout for phones, tablets and desktops
- Interactive 3D project spiral with tabs and live-site links
- Dark/light theme toggle (remembered between visits), sticky blurred header and scroll-to-top
- Visual feedback for mouse, touch, pen and keyboard (hover spotlight, press and tap ripple)
- Accessible: skip link, visible focus states, labelled form fields, and reduced-motion support
- Contact form (EmailJS) plus direct email, LinkedIn and GitHub links

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Geist and Geist Mono (Google Fonts), Remix Icon
- Layered CSS-only background (graphite gradient, dot grid, slow light beams, film grain and a hero spotlight)
- EmailJS integration for form messaging support

## Purpose

This portfolio demonstrates the ability to build a complete web experience from layout and styling to interactive behavior. It is intended for use in job applications, client outreach, and professional networking.

## Project Structure

- `index.html` — main landing page and portfolio content
- `assets/css/graphite.css`: theme, layout and responsive styles
- `assets/js/site.js`: core interactions (menu, theme, scroll, reveal, tap feedback, contact form); works even when opened from disk
- `assets/js/project-showcase.js`: project spiral and tabs
- `assets/js/main.js`: optional visual effects (decrypted text, custom cursor, magnetic buttons); needs to be served over http(s)
- `assets/img/` — portfolio visuals, icons, and graphic assets
- `assets/docs/` — supporting documents such as resume PDF

## Contact

Designed to support direct contact via email and social profiles, this project positions the creator as a well-rounded web developer ready to deliver modern digital experiences.
